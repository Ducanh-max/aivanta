# AIVANTA

AI-powered English Learning Platform.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Tech stack
- Next.js App Router
- React + TypeScript
- Lucide icons
- Custom responsive CSS

## Current milestone
Milestone 1: public landing page and visual direction. Authentication, learner dashboard, interactive lessons, AI tutor integration, and admin management will be added in subsequent milestones.
